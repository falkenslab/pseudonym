# Documentation site

Issue: [#6](https://github.com/falkenslab/pseudonym/issues/6)

## Goal

A Docusaurus site in `docs/`, published at `falkenslab.github.io/pseudonym`, that explains in detail how to install, integrate and operate the library and its CLI, and what it protects against.

## Context

- Today everything is in the README (about 260 lines): API, CLI, deny rules, data location. The threat model and legal frame live only in ADR-006.
- agent-kit already runs the same setup (Docusaurus 3, `docusaurus-plugin-typedoc`, local search, a `docs.yml` workflow to GitHub Pages, versioned docs); copy its structure, not its content.
- Decided with the owner: English only (ADR-004), versioned from the start, API reference generated by TypeDoc, the README shortened once the site exists.
- Needs `example-classroom-mcp.md` for its walkthrough page.

## Changes

- `docs/`: its own `package.json` (private) and lockfile; content in `docs/content/`, `sidebars.ts`, a small home page. Root scripts `docs:install`, `docs:start`, `docs:build`, `docs:version`.
- Sections:
  - **Guides**: installation; concepts (service, identifiers, alias, directory, per-service aliases, linking); integrating step by step; redacting free text and its limits; testing an integration.
  - **CLI**: installing it; resolving aliases; tidying the directory; backing up and moving the key; command reference with exit codes.
  - **Security and privacy**: threat model and what it doesn't protect against; GDPR frame (pseudonymization, legal basis, transfers, DPIA, from ADR-006, not legal advice); what redaction misses; keeping agents away from the key (the deny rules, what was tested and the gaps found, the sandbox); how it works inside (HMAC, HKDF subkeys, AES-256-GCM, matchers, lock and atomic write).
  - **Example**: a walkthrough of `examples/classroom-mcp`.
  - **API reference**: generated from `src/index.ts`'s doc comments.
- Versioning: `docs:version` snapshots `0.1.0` now; `main` shows as "next".
- `.github/workflows/docs.yml`: build on pull requests, publish to Pages on pushes to `main` that touch `docs/`, `src/` or the package files. Pages enabled with Actions as its source (`gh api`).
- `README.md`: shortened to what it is, install, a quick start, the essentials of safety, and links to the site; `homepage` in `package.json` points to the site.
- Skills: `update-docs` maps changes to pages and builds the site; `verify` runs `docs:build`; `release` snapshots the docs for each version.

## Acceptance

- `npm run docs:build` passes with no broken links or anchors, and every export has a doc comment in the API reference.
- The site is live at `https://falkenslab.github.io/pseudonym/` with a version selector showing 0.1.0 and next.
- Every command and function in the code appears in the site, and the README links to it.
